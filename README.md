# Project: Recipes

This is my first HTML project as part of **The Odin Project** curriculum. The project is a basic recipe website.

## Skills Demonstrated
- HTML boilerplate structure
- Headings, paragraphs, and lists (`<h1>`, `<p>`, `<ul>`, `<ol>`)
- Links (`<a href="...">`) and images (`<img src="...">`)
- Semantic HTML tags (`<strong>`, `<em>`)
- Git workflow (`add`, `commit`, `push`)
- GitHub Pages deployment

## Recipes Included
1. [Biryani](recipes/biryani.html)
2. [Burger](recipes/burger.html)
3. [Karahi](recipes/karahi.html)

## What I Learned
- How to structure an HTML project with multiple pages
- How to use relative paths for links and images
- How to use Git to track changes
- How to publish a website using GitHub Pages# Project-Recipes
